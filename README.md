# Yasin Alfatemi | ياسين الفاطمي

A personal developer portfolio for Yasin Alfatemi.

## Features
- Updated illustrated profile portrait
- Arabic greeting: اللهم صل وسلم على سيدنا محمد، والسلام عليكم
- English-first portfolio with Arabic name and greeting
- Responsive layout for desktop and mobile
- Public GitHub project gallery with search and category filters
- Project links, developer lab, and personal learning journey
- Dark/light theme
- Static blue background with no animated background or custom moving cursor

## Run locally
Open `index.html` in a modern browser. The portfolio loads public GitHub repositories and includes a fallback project list.
